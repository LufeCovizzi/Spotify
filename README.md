# 🎵 Spotify Clone

Este é um projeto de clone da interface do Spotify, desenvolvido com foco em praticar e aprimorar habilidades em **HTML**, **CSS** e **JavaScript**. A ideia é replicar visualmente o layout do Spotify Web, com estrutura responsiva e design moderno.

## 🔍 Pré-visualização

Veja uma demonstração do projeto: [Acesse aqui](https://lufecovizzi.github.io/Spotify/index.html)


## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript

## 📦 Funcionalidades

- Interface inspirada na versão web do Spotify
- Layout responsivo
- Elementos interativos com JavaScript (em construção)

## 🧠 Aprendizados
Durante o desenvolvimento deste projeto, pude reforçar e aprender:

- A estruturação semântica de páginas com HTML

- A aplicação de estilos avançados com CSS3

- O uso de Flexbox e Grid para construção de layouts responsivos

- A organização de arquivos em projetos web

- Os primeiros passos com interatividade utilizando JavaScript

## 📌 Próximos Passos
 - Aprimorar a responsividade para dispositivos móveis

 - Adicionar transições e animações para uma experiência mais fluida

 - Implementar funcionalidades interativas com JavaScript (simulação de player, playlists etc.)

 - Separar o CSS em múltiplos arquivos para organização modular

 - Refatorar para uso de componentes com JavaScript ou frameworks modernos (como React)
